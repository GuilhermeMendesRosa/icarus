## Como pesquisar

Use o caminho literal entre aspas ou pesquise todo o corpus:

```bash
rg -n -i -C 3 'progressão|progredir|platô' icaro
rg -n -i -C 3 'volume|séries válidas|frequência' icaro
rg -n -i -C 3 'dor|lesão|mobilidade|segurança' icaro
```

Leia linhas anteriores e posteriores antes de sintetizar. Trechos publicitários, brincadeiras, convidados e erros de reconhecimento não devem virar princípios.
